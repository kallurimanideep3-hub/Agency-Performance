Why this layout

Reading order is context (header), then filters, then the four headline numbers, then the explanation (trend, agents). Trend takes about two-thirds of the width because time is the main story; Top 10 is a ranking and needs less. The KPI strip sits above the charts because a leader on a phone at 7am wants the answer before the explanation. Slicers span the page because they filter everything. Footnote zone is reserved for the data-quality caveat so no number is unexplained.
